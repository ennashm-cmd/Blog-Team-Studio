📝 AI Blog Team Pro Studio

An advanced multi-agent workspace built with CrewAI and Streamlit that automates trend research, content drafting, and SEO optimization.

🚀 Key Features
🤖 Autonomous AI Team:

Trend Researcher: Scrapes live web trends via Serper.

Content Writer: Drafts engaging posts tailored to target word counts.

SEO Specialist: Adds high-ranking titles, keywords, and meta descriptions.

📂 Tabbed Dashboard Interface:

🏠 Home: Core studio to configure LLMs, select word counts, and run the AI crew.

📈 Insights: Tracks XP points, published metrics, and trend usage graphs.

📁 Activity: Content archive reviewing generated records over the past 30 days.

⚙️ Settings: Manages content preferences, external app integrations (WordPress/Medium), and schedulers.

❓ FAQ: Help center for workflows and tips.

👤 Sidebar Management: Securely input or update OpenAI and Serper API credentials alongside user profiles.
